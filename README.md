# YouTube-Transkript für Android

Kleine Android-App: YouTube-Link einfügen (oder in der YouTube-App auf **Teilen → Transkribieren** tippen) und das Transkript als Textdatei speichern, teilen oder kopieren.

- nutzt die Untertitel, die YouTube bereitstellt (manuell erstellt oder automatisch erzeugt)
- Wunschsprachen einstellbar, z. B. `de, en, fr`
- optional mit Zeitstempeln `[mm:ss]`
- heller und dunkler Modus, keine Werbung, keine Konten, keine Datensammlung

## APK bauen lassen (ohne eigenen Computer-Aufwand)

Bei jedem Hochladen baut GitHub die App automatisch:

1. Oben auf **Actions** klicken. Der Lauf „APK bauen“ dauert etwa 3–6 Minuten.
2. Grüner Haken = fertig. Rotes Kreuz = Fehler (den Lauf anklicken und die rote Zeile ansehen).
3. Auf der Startseite des Projekts rechts unter **Releases** die neueste Version öffnen und die Datei `YouTube-Transkript-….apk` herunterladen.

## Auf dem Handy installieren

1. Die APK-Datei auf dem Handy öffnen.
2. Wenn Android fragt: Installation aus dieser Quelle erlauben.
3. Falls Google Play Protect warnt („unbekannter Entwickler“): **Weitere Details → Trotzdem installieren**.

Neue Versionen lassen sich einfach über die alte installieren.

## Hinweise

- Automatisch erzeugte Untertitel enthalten oft keine Satzzeichen und Erkennungsfehler, besonders bei Namen.
- Videos ohne Untertitel können nicht transkribiert werden.
- Transkripte sind für den eigenen Gebrauch gedacht (Lernen, Notizen, Analyse). Die Inhalte gehören den Urhebern der Videos.
- Die App nutzt nicht-öffentliche Schnittstellen von YouTube. Ändert YouTube etwas, kann der Abruf vorübergehend scheitern.
